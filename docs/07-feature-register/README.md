# Feature Register

The feature register records how founding requirements map to actual implementation.

Each feature file should include:

- requirement IDs;
- founding requirement;
- implementation status;
- code locations;
- database objects;
- domain/application services;
- permissions;
- UI surfaces;
- tests;
- regulatory references;
- verification record;
- commits;
- outstanding gaps.

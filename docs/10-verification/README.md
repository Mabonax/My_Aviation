# Verification Evidence

This directory records evidence used to move requirements from `IMPLEMENTED` to `VERIFIED`.

## Verification record requirements

Every verification record should include:

- requirement ID;
- feature;
- implementation commit;
- relevant code locations;
- automated tests;
- permission/authorisation checks;
- workflow validation;
- regulatory source validation where applicable;
- build result;
- known limitations;
- final result.

Use `verification-template.md` when creating a new record.

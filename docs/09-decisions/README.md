# Architecture Decision Records

Architecture Decision Records (ADRs) preserve important decisions that should not be silently reversed by future implementation work.

## ADR lifecycle

- `PROPOSED`
- `ACCEPTED`
- `SUPERSEDED`
- `REJECTED`

## Initial ADRs

- ADR-001 — Domain architecture
- ADR-002 — Compliance state is derived
- ADR-003 — Regulatory rules are versioned data
- ADR-004 — Pilot logbook and aircraft flight folio are separate
- ADR-005 — SACAA is authoritative regulator
- ADR-006 — Mapping basemaps are not authoritative airspace data

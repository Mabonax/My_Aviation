# Development Log

This is the chronological engineering log for the VMT UAS platform.

Create one monthly file using `YYYY-MM.md`.

Each material implementation pass must record:

- date;
- commit;
- requirements advanced;
- code implemented;
- migrations/data changes;
- tests executed;
- build result;
- architectural impact;
- regulatory assumptions;
- outstanding work;
- documentation updated.

Git records *what changed*. This log records *what the change means relative to the product specification*.
